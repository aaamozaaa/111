# APK AI Studio (نسخه ۱.۰.۰)

**دستیار هوشمند، تحلیل‌گر باینری و اسکنر امنیتی فایل‌های APK اندروید**

---

## ۱. معرفی و هدف برنامه
**APK AI Studio** یک محیط مهندسی معکوس قانونی، تحلیل باینری، ممیزی امنیتی و دیباگ هوشمند برای برنامه‌های اندروید است. این اپلیکیشن به مهندسان اندروید و کارشناسان امنیت اجازه می‌دهد تا ساختار داخلی APKها، فایل‌های Manifest، مجوزها، کامپوننت‌های رجیستر شده و کلاس‌های DEX را به صورت کاملاً محلی (Local-First) بازرسی، عیب‌یابی و اصلاح نمایند.

> **تعهد قانونی و امنیتی:** این ابزار منحصراً برای اهداف تحلیل، بهینه‌سازی، امنیت و توسعه مجدد برنامه‌هایی است که شما مالک آن‌ها هستید یا مجوز قانونی بررسی آن‌ها را دارید. هیچ سازوکاری برای دور زدن لایسنس، حذف پرداخت‌های درون‌برنامه‌ای، سرقت توکن یا شکستن مکانیزم‌های حفاظتی در این نرم‌افزار وجود ندارد.

---

## ۲. قابلیت‌های واقعی پیاده‌سازی شده در نسخه 1.0.0

- **ورود و پردازش واقعی APK:**
  - انتخاب و باز کردن فایل‌های `.apk` از حافظه سیستم یا دستگاه.
  - پارسر اختصاصی باینری AndroidManifest (AXML Parser) بدون وابستگی به ابزارهای خارجی.
  - پارسر ساختار باینری Dalvik Executable (DEX Parser) جهت استخراج متدها، کلاس‌ها، فیلدها و رشته‌ها.
  - محاسبه اثر انگشت SHA-256، بررسی گواهی و فایل‌های `META-INF/`.
  - استخراج پکیج، نام نسخه، کد نسخه، minSdk، targetSdk و معماری‌های CPU (مانند arm64-v8a).
- **اسکنر امنیتی (Security Scanner & Score):**
  - ارزیابی خودکار و محاسبه نمره امنیت (۰ تا ۱۰۰) و رتبه کیفی (A+, A, B, C, D, F).
  - کشف آسیب‌پذیری‌های فعال بودن حالت Debuggable، ترافیک متنی بدون رمزنگاری (Cleartext Traffic)، بک‌آپ ناامن (allowBackup) و فقدان Network Security Config.
  - تشخیص کامپوننت‌های صادر شده بدون محافظت (Unprotected Exported Components).
  - پویشگر رشته‌های حساس، توکن‌های JWT، کلیدهای دسترسی Google API / AWS و آدرس‌های IP مستقیم.
- **اسکنر و طبقه‌بندی مجوزها (Permissions):**
  - دسته‌بندی مجوزها به دسته‌های خطرناک (Dangerous)، معمولی (Normal)، ویژه (Special) و سیستمی.
  - ارائه توضیحات و کاربردهای متداول به زبان فارسی برای هر مجوز.
  - امکان اتصال به AI برای پاسخ به «چرا این مجوز استفاده شده است؟».
- **اکسپلورر کد و فایل (Code & File Explorer):**
  - نمایش درختی تمام فایل‌های داخل APK (`AndroidManifest.xml`, `classes.dex`, `res/`, `assets/`, `lib/`, `META-INF/`).
  - مشاهده محتوا، کپی در کلیپ‌بورد، دانلود فایل منفرد و جستجوی سریع.
  - اینسپکتور کلاس‌های DEX با نمایش امضای متدها، ارث‌بری و تحلیل عملکردی با AI.
- **دستیار هوش مصنوعی (AI Assistant):**
  - اتصال سمت سرور به مدل پرچمدار `gemini-3.8-flash` با امنیت کامل کلیدها.
  - پشتیبانی از بافت اختصاصی پروژه (ارسال هدفمند اطلاعات با حفظ حریم خصوصی).
  - ارجاع دقیق به نام فایل‌ها و پکیج‌ها در پاسخ‌ها.
- **ایجنت هوشمند دیباگ (AI Agent Workflow):**
  - چرخه ۱۰ مرحله‌ای خودمختار برای حل مشکلات اعلامی کاربر (از تحلیل، کشف ریشه، فرمول‌بندی پچ، تایید با مقایسه BEFORE vs AFTER، تا بیلد و اعتبارسنجی نهایی).
- **کنترل تغییرات، اسنپ‌شات و بازگردانی (Rollback):**
  - ثبت اتوماتیک Snapshot قبل از هرگونه اعمال تغییر یا ویرایش منیفست.
  - امکان Rollback و بازگردانی فوری به هر نسخه پشتیبان.
  - ویرایشگر مستقیم کدهای XML منیفست با ذخیره آنی.
- **پایپ‌لاین بیلد و امضای مجدد (Build & Signing Pipeline):**
  - بسته‌بندی مجدد و اعمال تغییرات روی فایل APK.
  - تولید فایل‌های امضای JAR و V1 (`MANIFEST.MF`, `CERT.SF`, `CERT.RSA`).
  - دانلود مستقیم فایل `.apk` امضا شده نهایی در مرورگر.
- **مقایسه دو نسخه (Version Diff):**
  - مقایسه متغیرهای دو نسخه APK: مجوزهای حذف یا اضافه شده، تفاوت‌های کامپوننت‌ها و تفاوت امتیاز امنیت.
- **لاگ‌ها و خروجی گزارش (Reports):**
  - ثبت سوابق تحلیلی، وقایع هوش مصنوعی و خطاهای بیلد.
  - صدور گزارش رسمی در دو فرمت HTML (زیبا، واکنش‌گرا و آماده پرینت) و TXT.
- **پشتیبانی PWA و موبایل:**
  - قابل نصب مستقیم روی گوشی‌های اندروید به صورت اپلیکیشن مستقل (Standalone PWA / WebAPK).
  - پشتیبانی کامل از چینش راست‌به‌چپ (RTL) و حالت دارک/لایت.

## ۳. نحوه نصب و اجرای برنامه روی اندروید و سیستم

### روش ۱: نصب مستقیم روی گوشی اندروید (PWA / WebAPK)
این اپلیکیشن مطابق با استانداردهای رسمی Progressive Web App پیاده‌سازی شده است:
1. آدرس برنامه را در مرورگر Google Chrome گوشی اندروید خود باز کنید.
2. روی دکمه **«نصب برنامه (PWA)»** در نوار بالای برنامه بزنید (یا از منوی سه نقطه مرورگر، گزینه **«افزودن به صفحه اصلی» / Add to Home Screen** را لمس کنید).
3. اپلیکیشن با نام و آیکون اختصاصی بر روی گوشی شما نصب شده و مانند یک برنامه Native اندروید بدون نوار مرورگر اجرا می‌شود.

### روش ۲: اجرای پروژه از روی Source Code
برای توسعه محلی روی رایانه:
```bash
# نصب پکیج‌ها
npm install

# اجرای سرور در حالت توسعه
npm run dev

# ساخت نسخه پروداکشن
npm run build
npm run start
```
برنامه بر روی پورت `http://localhost:3000` اجرا خواهد شد.

## ۴. تنظیمات هوش مصنوعی Gemini
- ارتباط با مدل هوش مصنوعی از طریق سرور امن داخلی و مدل `gemini-3.8-flash` انجام می‌شود.
- کلید API در متغیر محیطی `GEMINI_API_KEY` در سرور پیکربندی می‌گردد و هرگز به سمت کلاینت یا مرورگر افشا نمی‌شود.
- در منوی **تنظیمات (Settings)**، دکمه **«تست اتصال»** قرار دارد که با ارسال یک درخواست پینگ، وضعیت سلامت ارتباط با Gemini را فوراً گزارش می‌دهد.
- گزینه **«حریم خصوصی و ارسال داده به AI»** به شما اجازه می‌دهد مشخص کنید آیا اطلاعات APK جهت بررسی برای مدل فرستاده شود یا صرفاً تحلیل محلی انجام پذیرد.

## ۵. شفافیت درباره محدودیت‌های محیط و قابلیت‌های آینده

### شفافیت محیط ساخت:
این برنامه در یک محیط Full-Stack مدرن (Node.js/TypeScript/React/Express) اجرا می‌شود. بنابراین:
- **تحلیل باینری و دیکامپایل:** با پارسرهای سفارشی داخل پروژه (AXML Parser & DEX Parser) مستقیماً روی باینری APK اجرا شده و به هیچ سرور خارجی نیاز ندارد.
- **ساخت مجدد و امضا:** بسته APK خروجی از طریق ماژول `apkSigner` تولید، هش‌بندی، با امضای استاندارد V1 JAR امضا شده و به عنوان یک فایل معتبر `.apk` در اختیار شما قرار می‌گیرد.
- **نصب Native از طریق Gradle:** به دلیل نبود دیمن سنگین Android SDK / Gradle در کانتینر ابری تحت وب، تولید بایت‌کد جاوا به دکس باینری برای کدهای جدید از طریق موتور داخلی مدیریت می‌شود و برای کامپایل کاتلین کامل می‌توانید سورس‌های خروجی را در Android Studio بیلد کنید.

### مواردی که در نسخه‌های بعدی (v1.1+) اضافه خواهند شد:
- دیکامپایل کامل بایت‌کد DEX به کدهای معادل Smali و Java در داخل مرورگر.
- اتصال مستقیم به دستگاه از طریق WebUSB / WebADB برای دستورات لایو Logcat.
- پشتیبانی از موتورهای چندگانه هوش مصنوعی مانند Local LLMs (Ollama / WebLLM).
